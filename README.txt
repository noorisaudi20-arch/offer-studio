Offer Studio — ملف جاهز للنشر على GitHub Pages

يتضمن index.html التطبيق وبيانات الأصناف المضمّنة. انشر الملف في مستودع GitHub عام، ثم فعّل Settings > Pages واختر النشر من فرع main ومجلد الجذر (/root). سيكون الموقع متاحاً عبر رابط Pages الخاص بالمستودع.

ملاحظة: التطبيق يحتاج اتصال إنترنت لتحميل مكتبة استيراد Excel من jsDelivr؛ الطباعة وبيانات الأصناف تعمل في المتصفح بعد تحميل الصفحة.
